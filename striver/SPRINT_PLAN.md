# Sprint Plan — Cadence View

Companion to `../DSA_PREP.md` (method) and `ROADMAP.md` (pattern→problem map).
This file is the **time view**: sprints → weeks → daily cadence → "done".

- Budget: **6 hrs/week = 3 sessions × 2 hrs.** ~5 problems/week.
- A **sprint = 1 month = 4 weeks**: 3 pattern weeks + 1 review/mock week.
- **Missed a week? Do NOT catch up.** Resume the next week. Consistency > completion.

---

## Daily cadence (every pattern week)

| Day | 2 hrs | Focus |
|-----|-------|-------|
| **Day 1** | Learn the pattern (read `patterns.md` entry) + 2 problems: 1 I walk you through as a model, 1 you solve | Recognition + template |
| **Day 2** | 1 Medium + 1 Medium/Hard, solo | Communication, complexity, clean code |
| **Day 3** | Re-solve 1–2 old problems from memory + 1 new same-pattern problem + update `NOTES.md` | Retention + mistake review |

**Per-problem loop (the protocol):** read → state brute force out loud → optimal idea →
why it's better → complexity → code → I review → 2–3 follow-ups → `NOTES.md` entry.

## Definition of Done (per pattern week)
- [ ] All week's `.py` files solved and passing their `__main__` tests.
- [ ] Each has filled-in `Brute / Optimal / Time-Space` docstring lines.
- [ ] `NOTES.md` entry written for every problem (the real revision material).
- [ ] Can re-derive the pattern's template from a blank file, no reference.
- [ ] Can recognize the pattern from the problem statement in < 2 min.
